# Aadhaar Enrolment and Update Trend Analysis

This repository contains a data analysis project developed as part of a UIDAI data challenge to identify trends and patterns in Aadhaar enrolment and update activities.

## Project Overview
The project analyzes aggregated Aadhaar enrolment, demographic update, and biometric update datasets to understand how Aadhaar services are used across age groups, districts, and time. The analysis focuses on district-level data from Maharashtra and uses monthly aggregation to ensure clarity and privacy.

## Datasets
The analysis uses aggregated datasets provided by the Unique Identification Authority of India (UIDAI):
- Aadhaar Enrolment Dataset
- Aadhaar Demographic Update Dataset
- Aadhaar Biometric Update Dataset

## Methodology
- Filtered data for Maharashtra
- Standardized dates and aggregated records monthly
- Performed age-wise and district-wise analysis
- Visualized trends using line graphs and heatmaps

## Visualisations
The notebook generates:
- Age-wise monthly trend plots
- District-wise heatmaps showing activity intensity

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Reproducibility
The analysis workflow is fully documented in the Jupyter Notebook. The notebook can be executed end-to-end once the datasets are available.
